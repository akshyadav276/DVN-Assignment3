# Documentation Index

This folder contains the assignment-facing documentation for the Tableau final portfolio.

| File | Purpose |
|---|---|
| `data_dictionary.csv` | Mandatory data dictionary with variable definitions, types, provenance, and dashboard use. |
| `data_dictionary.md` | Human-readable summary of dataset grains, important fields, joins, and cautions. |
| `methodology.md` | Cleaning, integration, join logic, and dashboard-ready data model notes. |
| `user_persona_and_stories.md` | Single stakeholder persona, user stories, acceptance criteria, and definition of done. |
| `visual_design_principles.md` | Gestalt, pre-attentive, cognitive load, and accessibility rationale. |
| `limitations.md` | Analytical limitations and responsible-use caveats. |
| `dashboard_story.md` | Written narrative flow behind the Tableau story and final dashboard. |
| `credits.md` | Supporting credits for data sources, tools, and collaboration platforms. |
