# User Persona And Stories

## Stakeholder Hat

Australian Transport Minister / Road Safety Funding Committee.

## Persona

The stakeholder needs a concise, evidence-led view of where road-safety intervention should be prioritised. They need to understand national scale, current urgency, fair state-level risk, repeatable fatality patterns, and the potential impact of targeted action.

## User Stories

| User Story | Acceptance Criteria |
|---|---|
| As a Transport Minister, I want to see whether fatalities are improving over time so that I can understand policy urgency. | Dashboard includes a historical fatality trend and latest-period KPI. |
| As a policy adviser, I want fair state comparison so that funding is not based only on raw fatality counts. | Dashboard includes fatalities per 100,000 people. |
| As a road safety strategist, I want to identify repeatable risk patterns so that interventions can be targeted. | Dashboard shows time, remoteness, speed, and road-user patterns. |
| As a decision-maker, I want to test intervention impact so that I can justify action. | Dashboard includes a what-if lives-saved parameter. |
