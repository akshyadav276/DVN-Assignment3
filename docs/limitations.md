# Limitations

- BITRE fatality records include year and month, but not exact crash date in the supplied fatality file. Weather is therefore joined as state-month context, not crash-day causation.
- Population data is available to 2025. January 2026 fatality rows remain in the dashboard, but they are excluded from annual population-normalised rate comparisons.
- Historical remoteness, SA4, LGA, and road-type fields contain many unknown values. Detailed road-environment analysis focuses on the latest 2024-Jan 2026 policy window where these fields are more complete.
- Weather uses representative state-level locations and should be interpreted as contextual enrichment.
