# Visual Design Principles

## Gestalt Principles

- Proximity: group dashboard sections into scale, risk, pattern, and action.
- Similarity: use consistent colour encoding for fatality risk.
- Common region: visually separate KPI, evidence, diagnosis, and decision areas.
- Continuity: guide the reader from long-term context to action.

## Pre-Attentive Attributes

- Use colour intensity to highlight higher fatality counts or risk.
- Sort bars by risk so priority is visible without extra reading.
- Use large KPI typography for the most important numbers.
- Highlight the latest policy window distinctly from historical context.

## Cognitive Load Optimisation

- Use one primary dashboard page.
- Keep visuals purposeful and avoid decorative charts.
- Move secondary details such as weather and heavy vehicles into tooltips.
- Use plain labels such as "fatalities per 100,000" and "potential lives saved".

## Accessibility

- Use high-contrast text and backgrounds.
- Avoid relying on red/green alone.
- Keep labels readable and tooltips concise.
