# Data Preparation Track

This folder holds the code-track work for Assignment 3.

## Workflow

1. `01_Data_cleaning/` - dataset-specific cleaning notebooks.
2. `02_integration/` - joins and dashboard-ready master files.
3. `03_eda/` - exploratory summaries that informed the dashboard story.
4. `04_tableau_inputs/` - final Tableau input preparation.

## Rules

- Keep raw data unchanged.
- Document every cleaning rule.
- Validate row counts before and after joins.
- Use cleaned BITRE fatality records as the row-level Tableau base.
- Use state-year population data for fatalities per 100,000 population.
